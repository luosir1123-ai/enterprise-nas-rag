# 知识库同步与自动评测运维说明

## 数据保留策略

新 NAS `192.168.1.90` 是当前增量资料源，旧 NAS 已导入 RAGFlow 的资料作为历史快照保留。同步任务不会因为文件未出现在新 NAS 就删除历史文档。

| 状态 | 含义 | 处理方式 |
| --- | --- | --- |
| `active` | 当前 NAS 可见 | 新增或修改后自动解析 |
| `historical` | 旧 NAS 历史资料 | 保留检索，不自动删除 |
| `missing_from_source` | 曾属于当前 NAS，后来被移除 | 保留索引并标记，等待人工确认 |
| `duplicate_current_path` | 当前 NAS 中同名同大小的重复路径 | 共用一个索引对象 |

增量同步由 `com.waimao.ragflow-nas-sync` 每小时运行，单批最多处理 300 项，内容新增和修改优先于元数据迁移。

日志目录：

```text
~/Library/Logs/waimao-ragflow/incremental_sync/
```

## 自动评测

自动评测由 `com.waimao.ragflow-evaluation` 每周一 `04:10` 运行。

- `source_coverage`：三库各 20 条，检查指定来源召回和无证据拒答。
- `business_accuracy`：12 条，检查型号、表格数值、引用来源和拒答门槛。
- 默认三路并发，单题 120 秒超时。
- 报告保留 90 天。

日志目录：

```text
~/Library/Logs/waimao-ragflow/evaluation/
```
