# 评估集说明

## 评估集是什么

评估集是用来检查企业 RAG 是否真的会找资料、真的会引用资料、真的会拒答的题目集合。

## 为什么必须先做评估集

企业 RAG 不能只看“能不能回答”，还要看：

- 回答是不是来自真实文件
- 回答有没有引用来源
- 找不到证据时会不会乱编
- 权限外内容会不会被检索到

所以评估集不是附加项，而是验收标准。

## 每条评估问题要写什么

每条问题至少写下面这些字段：

- `question`
- `expected_answer`
- `source_file`
- `source_section_or_page`
- `knowledge_base`
- `must_refuse_if_no_evidence`

## 怎么理解 `must_refuse_if_no_evidence`

- `true`：这道题没有明确证据，系统必须拒答。
- `false`：这道题可以从文件里找到答案。

## 三个知识库的评估重点

### 采购知识库

重点看：

- 供应商信息
- 采购流程
- 报价
- 合同条款
- 物料资料

### 销售知识库

重点看：

- 客户资料
- 报价方案
- 销售合同
- 项目记录

### 产品设计知识库

重点看：

- 产品方案
- 设计文档
- BOM
- 评审材料
- 技术资料

## 评估时最重要的判断

- 能不能找到来源文件
- 能不能定位到页码或章节
- 答案是否和来源一致
- 无证据时是否拒答
- 是否混入了无权限内容

## 这一步和后面检索服务的关系

先有评估集，后面才能判断检索服务是不是可靠。
没有评估集，就只能凭感觉判断结果好不好。
