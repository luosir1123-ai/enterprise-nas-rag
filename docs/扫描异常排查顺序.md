# 扫描异常排查顺序

如果 `scan_nas.py` 跑出来不对，先按这个顺序查，不要直接改问答层。

## 1. 先查挂载

- `/mnt/nas/PUR-SHR` 是否真的挂上了
- `/mnt/nas/SALES-SHR` 是否真的挂上了
- `/mnt/nas/product-design` 是否真的挂上了
- `mount | grep /mnt/nas` 是否能看到只读挂载

## 2. 再查权限

- `rag_reader` 是否只被授权三个目录
- NAS 上共享名是否写对
- SMB/NFS 协议是否已经启用

## 3. 再查配置

- `configs/knowledge_bases.yaml` 的 `local_scan_path` 是否指向挂载点
- `external_mount_path` 是否和挂载点一致
- `include_extensions` 是否写对

## 4. 再查排除规则

- `configs/exclude_patterns.yaml` 是否把正常文件误排除了
- 是否把目录名写错了
- 是否把扩展名误加入黑名单

## 5. 再查文件本身

- 目录里是否真的有可纳入的 Office / PDF / 文本文件
- 是否全是压缩包、图片或临时文件
- 是否目录路径本身就是空的

## 6. 再查脚本输出

- 是否所有文件都被标成 `excluded`
- 是否出现 `missing_scan_path`
- 是否出现 `stat_error`
- 是否候选文件数为 0

## 7. 最后才查样本和评估

- 清单不对时不要先写评估题
- 先把真实清单弄对，再做抽样和评估

## 排查原则

先确认数据源能看见，再确认权限能隔离，再确认规则没误杀，最后才谈抽样和检索。
